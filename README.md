# دستیار سه‌هوشه | Dastیار 3Houshe

نسخهٔ اولیهٔ رابط وب/موبایل برای مقایسهٔ پاسخ ChatGPT، DeepSeek و Microsoft Copilot.

## وضعیت فعلی
این مخزن شامل نمونهٔ اولیهٔ سمت کاربر است:
- رابط فارسی و راست‌چین با تشخیص جهت متن انگلیسی
- نمایش وضعیت اتصال سه سرویس
- تاریخچهٔ محلی گفتگو با localStorage
- ورودی گفتار و خواندن متن با قابلیت‌های موجود مرورگر
- ساختار مناسب بازکردن و ویرایش در Cursor

**اتصال واقعی مدل‌ها هنوز فعال نیست.** برای دریافت پاسخ واقعی باید APIهای مجاز و یک Backend امن پیکربندی شوند. کلید API را در فایل‌های مخزن یا APK قرار ندهید.

## اجرا
فایل `web/index.html` را در مرورگر باز کنید یا پوشهٔ `web` را با یک وب‌سرور محلی اجرا کنید. برای میکروفون معمولاً HTTPS یا localhost لازم است.

## کار با Cursor
1. مخزن را در Cursor کلون/باز کنید.
2. فایل `docs/SECURITY.md` را بخوانید.
3. تغییرات را در branch جداگانه انجام دهید و سپس commit/push کنید.

## مسیرهای پروژه
- `web/index.html` رابط برنامه
- `web/styles.css` ظاهر واکنش‌گرا
- `web/app.js` تاریخچه، گفتار و مدیریت رابط
- `docs/SECURITY.md` الزامات امنیتی اتصال API

## نقشهٔ راه
1. نمونهٔ اولیهٔ رابط و تاریخچهٔ محلی
2. Backend امن و اتصال APIهای ChatGPT و DeepSeek
3. بررسی راهکار رسمی Copilot؛ در غیر این صورت بازکردن جداگانه و ورود دستی پاسخ
4. تست گفتار فارسی روی Android WebView
5. بسته‌بندی APK و تست روی گوشی

## مجوز
پیش از انتشار عمومی، مجوز پروژه تعیین شود.
