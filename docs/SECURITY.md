# امنیت اتصال سرویس‌ها

کلیدهای API مربوط به OpenAI، DeepSeek یا هر ارائه‌دهندهٔ دیگر نباید در HTML، JavaScript سمت کاربر، APK، مخزن GitHub یا پیام‌های گفتگو قرار بگیرند.

## معماری موردنیاز
برنامه درخواست را به Backend متعلق به پروژه می‌فرستد. Backend باید:
1. درخواست را اعتبارسنجی و محدودسازی نرخ کند.
2. کلید سرویس را از متغیر محیطی یا Secret Manager بخواند.
3. درخواست را به API رسمی ارائه‌دهنده بفرستد.
4. خروجی را با ساختار یکسان به برنامه برگرداند.
5. خطا، سهمیه و هزینه را مدیریت کند؛ کلیدها و متن خصوصی کاربران را در log ثبت نکند.

## Copilot
از استخراج کوکی، دور زدن ورود یا روش‌های غیررسمی استفاده نشود. فقط API یا مجوز رسمی و قابل استفاده بررسی شود؛ در غیر این صورت Copilot جداگانه باز شود و کاربر پاسخ را دستی وارد کند.

## پیش از انتشار
- HTTPS اجباری
- محدودیت اندازه و نرخ درخواست
- احراز هویت و کنترل سوءاستفاده
- عدم ذخیرهٔ کلید در LocalStorage
- سیاست حریم خصوصی و امکان حذف تاریخچه
- تست امنیتی Backend و بررسی هزینه‌ها

## محدودیت نسخهٔ فعلی
این نسخه فقط تاریخچه را در LocalStorage همان مرورگر نگه می‌دارد و پاسخ واقعی مدل‌ها را دریافت نمی‌کند. داده‌ها با پاک‌کردن داده‌های مرورگر یا حذف برنامه ممکن است از بین بروند. گفتار به پشتیبانی مرورگر و مجوز میکروفون وابسته است.
